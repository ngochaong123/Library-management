# 📚 Library Management

## 📌 Introduce 
Library Management is a library management system that supports functions such as book management, users, borrowing/returning books, catalog classification, and shelf tracking. The project is built with **Node.js + Express** as backend, **MySQL** for data management, and **ApexCharts** for displaying statistical charts.

## 🚀 Technology used
- **Frontend:**
- React + TypeScript → Build a flexible user interface.
- ApexCharts → Display statistical charts such as the number of books borrowed by time, category, user.

- **Backend:**
- **Node.js + Express** → Build a RESTful API to handle library logic.
- **MySQL** → Store and query data.
- **Express Router** → Separate functionality into clear API routes.

## 🔧 Installation Guide

### Prerequisites:

- Node.js

- MySQL server has been set up

### Frontend installation:

```sh
git clone https://github.com/ngochaong123/Library-management.git
cd Library-management
npm install
npm start # Start the website

```

### Backend installation:

```sh
npm install
npm start # Run the backend server

```


### 🎯 Main features
- ✔️ CRUD books, users, categories and loan/return transactions.

- ✔️ RESTful API to manipulate library data.

- ✔️ Intuitive, easy-to-use user interface.

- ✔️ Flexible data query from MySQL.
- ✔️ ApexCharts statistical charts help display library data visually.
